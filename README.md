# 📼 Mixtape APP

Um aplicativo em Flutter para criar e compartilhar mixtapes digitais com uma vibe retrô. Reviva a nostalgia de montar a playlist perfeita para alguém especial.

![Placeholder para GIF do App](https://via.placeholder.com/800x450.png?text=GIF+do+App+Aqui)

## ✨ Funcionalidades

-   **Criação de Mixtapes:** Dê um título, escolha um destinatário e escreva uma mensagem de abertura.
-   **Busca de Músicas:** Encontre suas faixas favoritas usando a API do iTunes.
-   **Temas Retrô:** Personalize a aparência de cada fita com temas como "Pôr do Sol", "Noite", "Floresta" e mais.
-   **Player Integrado:** Ouça as prévias das músicas diretamente no app.
-   **Exportação para PDF:** Gere um encarte de PDF lindamente estilizado para cada mixtape, pronto para compartilhar.
-   **Backup e Restauração:** Exporte e importe toda a sua coleção de fitas em formato JSON.

## 🚀 Como Executar

1.  **Clone o repositório:**
    ```bash
    git clone https://github.com/pedroliveiraa/Mixtape-APP.git
    cd Mixtape-APP
    ```

2.  **Instale as dependências:**
    ```bash
    flutter pub get
    ```

3.  **Execute o aplicativo:**
    ```bash
    flutter run
    ```

## 🛠️ Construído Com

-   **Flutter** - O framework de UI do Google para criar aplicativos nativos para mobile, web e desktop a partir de uma única base de código.
-   **GoRouter** - Para navegação e roteamento.
-   **Just Audio** - Para tocar as prévias das músicas.
-   **PDF/Printing** - Para a geração e compartilhamento dos encartes em PDF.
